## 它解决什么问题

“要不要上这条新产线？”“要不要接这个大客户的低价订单？”结果取决于未来的市场情况，没人能确定。期望值方法把不确定性拆成几种可能情景，给每种情景一个概率和结果，然后算出“平均来看”哪个方案更好。

## 核心公式

期望值 = Σ（每种结果的概率 × 该结果的收益）

## 怎么做

1. **列出方案**，包括“不做”。
2. **为每个方案列出可能的情景**，一般 2～4 个，例如“需求旺盛 / 一般 / 低迷”。
3. **估计每种情景的概率**，同一方案的概率之和必须等于 100%。概率可以来自历史数据、行业数据或专家判断。
4. **估计每种情景下的结果**，通常用利润或[净现值](#/kb/npv)。
5. **计算期望值，同时看三个风险指标**：最坏结果、亏损概率、结果的离散程度（标准差）。
6. **画成决策树**：方块表示决策点，圆圈表示不确定事件，从右往左逐层计算期望值（“回滚”）。

[期望值计算工具](#/tools/ev)可以直接比较多个方案。

## 示例

| 方案 | 情景 | 概率 | 利润（万元） |
|---|---|---|---|
| 扩建产线 | 需求旺盛 | 40% | 800 |
| | 需求一般 | 40% | 200 |
| | 需求低迷 | 20% | −500 |
| 外包代工 | 需求旺盛 | 40% | 400 |
| | 需求一般 | 40% | 150 |
| | 需求低迷 | 20% | −50 |

- 扩建：期望值 = 0.4×800 + 0.4×200 + 0.2×(−500) = 300 万元，最坏亏 500 万元
- 外包：期望值 = 0.4×400 + 0.4×150 + 0.2×(−50) = 210 万元，最坏亏 50 万元

扩建的期望值更高，但如果公司账上现金只有 600 万元，亏 500 万元会危及生存，选择外包可能更明智。**期望值最大不等于最好的决策，要结合承受能力。**

## 常见误区

- **概率拍脑袋且过于乐观**：可以请不同的人独立估计再讨论，或参考同类项目的实际成功率。
- **忽视小概率的灾难性结果**。
- **情景过多过细**，看起来精确，实际误差更大。
