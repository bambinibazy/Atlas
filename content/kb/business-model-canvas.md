## 它解决什么问题

“我们是怎么赚钱的？”很多团队回答不清楚，或者每个人说的不一样。亚历山大·奥斯特瓦德和伊夫·皮尼厄在 2010 年出版的《商业模式新生代》中提出画布，把商业模式拆成九块，一页纸画完。

## 九个模块

| 模块 | 问题 |
|---|---|
| 客户细分 | 我们为谁创造价值？谁是最重要的客户？ |
| 价值主张 | 我们帮客户解决什么问题、满足什么需求？ |
| 渠道 | 通过什么途径触达客户、交付价值？ |
| 客户关系 | 和客户建立什么样的关系（自助、专属服务、社群）？ |
| 收入来源 | 客户愿意为什么付钱？怎么付（一次性、订阅、按量、佣金）？ |
| 核心资源 | 需要哪些关键资源（人才、技术、品牌、资金、数据）？ |
| 关键业务 | 必须做好哪些关键活动？ |
| 重要合作 | 依赖哪些合作伙伴和供应商？ |
| 成本结构 | 最主要的成本是什么？固定还是变动？ |

右半边（客户、价值、渠道、关系、收入）讲价值创造和获取，左半边（资源、业务、合作、成本）讲如何高效交付。

## 怎么做

1. **从客户细分和价值主张开始**，它们是画布的核心。每个客户细分最好对应一个清晰的价值主张。
2. **用便利贴填写**，便于讨论和修改。一张便利贴只写一件事。
3. **检查一致性**：渠道能否触达这类客户？收入方式是否和客户的支付习惯匹配？
4. **把收入和成本量化**：单位经济模型（每个客户的收入、获客成本、服务成本）是否成立？可以用[本量利分析](#/kb/cvp)估算盈亏平衡点。
5. **画出替代方案**：同一价值主张，换一种收入方式（比如从卖设备改为卖服务）会怎样？

## 常见误区

- **价值主张写成产品功能。** “我们有 AI 推荐”是功能，“帮门店店长每天少花一小时排班”才是价值。
- **客户细分太宽。** “所有中小企业”不是细分，要具体到行业、规模和痛点。
- **画完不验证。** 画布是一组假设，需要通过客户访谈、小规模试点来验证。
